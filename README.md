# AutoHH — Автоматический отклик на вакансии HH.ru (Mobile API + ИИ)

Telegram-бот для автоматической рассылки откликов на вакансии HH.ru. Проект работает через **официальный мобильный REST API HH.ru** (`api.hh.ru`), авторизуясь OAuth-токеном Android-приложения HH — **без браузера и Playwright**. ИИ Gemini генерирует сопроводительные письма и оценивает релевантность вакансий.

---

## Требования для работы

1. **Резюме на аккаунте HH.ru**: минимум одно резюме. Резюме для отклика выбирается в настройках потока (Flow) по его ID.
2. **Авторизация по OAuth (Mobile API)**: вход выполняется через официальный OAuth-флоу HH.ru — бот присылает ссылку `https://hh.ru/oauth/authorize?...`, вы логинитесь в браузере и вставляете боту параметр `code=` из адресной строки. Бот обменивает код на токены и сохраняет их в БД (авто-продление access-токена через refresh-токен).

## Быстрый старт

### 1. Подготовка конфигурации
```bash
cp .env.example .env
```
Обязательные переменные:
* `TG_BOT_TOKEN` — токен вашего Telegram-бота, полученный у @BotFather.
* `TG_ALLOWED_USERS` — список числовых Telegram ID через запятую, которым разрешен доступ к боту.
* `GEMINI_API_KEY` — API-ключ Gemini, полученный в Google AI Studio.

Опционально: `TG_PROXY_URL`, `GEMINI_PROXY_URL`, `PROXY_URL` (прокси для запросов к HH.ru API), `DATA_DIR`, `LOG_LEVEL`.

### 2. Запуск контейнеров
```bash
docker-compose up -d --build
```

### 3. Авторизация в HH.ru через Telegram
1. Отправьте боту `/start`.
2. Откройте `⚙️ Настройки` → `📱 Авторизация HH (API)`.
3. Откройте присланную ссылку в браузере и авторизуйтесь в HH.ru.
4. Скопируйте из адресной строки значение параметра `code=...`.
5. Отправьте код боту. Токен сохранен — бот работает через мобильный API.

## Основные возможности

### Режимы работы
* **Ручной режим (Manual Run)**: запускается кнопкой `▶️ Запуск`. Прогоняет активный поток до лимита откликов за запуск (`Target Applies`) или суточного лимита.
* **Режим мониторинга (Monitoring Run)**: фоновый режим, отслеживает новые вакансии по расписанию. Бот добавляет к ссылкам поиска сортировку по дате (`order_by=publication_time`), чтобы проверять только свежие объявления.

### Алгоритм плавающей границы в мониторинге
1. **Инициализация**: при первом включении бот запоминает ID самой свежей вакансии первой страницы как начальную границу. На этом шаге он **не откликается**.
2. **Фоновые проверки**: если первая вакансия совпадает с сохраненной границей — новых вакансий нет, проверка завершается. Иначе бот обходит новые вакансии сверху вниз до достижения границы.
3. **Сдвиг границы**: по завершении обхода граница сдвигается на ID самой свежей вакансии запуска.
4. **Cache-Hit Early Exit**: если якорная вакансия удалена/заархивирована, бот останавливает обход при 2 последовательных уже известных вакансиях и обновляет границу по первой из них — не сканируя все 40 страниц.

### Мобильный API и устойчивость
* **Без браузера/капчи от верстки**: все операции (поиск, чтение вакансии, отклик, поднятие резюме) идут через `api.hh.ru` с OAuth-токеном Android-приложения.
* **Случайный Android User-Agent**: на каждый процесс генерируется реалистичный UA мобильного приложения (модель устройства, версия Android, UUID) — как в референсном инструменте.
* **Anti-fraud паузы и лимиты**: случайные задержки между запросами (минимальная пауза 0.4 с на API-уровне), суточный/почасовой лимиты и расписание из настроек потока.
* **Обработка капчи**: если API вернет `captcha_required`, бот приостанавливает текущий запуск и запрашивает решение у пользователя.
* **Авто-продление токена**: при `403 oauth`/истечении срока access-токен обновляется через refresh-токен и запрос повторяется.
* **VacancyLockManager**: `asyncio.Lock`-диспетчер исключает параллельную обработку одной вакансии ручным и фоновым планировщиками.

### Кэширование и фильтрация
* **Канонический кэш по Vacancy ID**: история откликов и кэш описаний ключуются по числовому ID вакансии (например, `135695543`), а не по URL с произвольными GET-параметрами HH.ru.
* **Черный список компаний** (на уровне потока): совпадение подстроки регистронезависимо, вакансия пропускается без обращения к ИИ.
* **Умное сопроводительное письмо**: Gemini генерирует краткий текст (2-3 предложения) по стеку вакансии и резюме.
* **Приоритет пользовательских промптов**: пользовательские инструкции изолируются в блок `START/END OF USER CUSTOM INSTRUCTIONS` с директивой наивысшего приоритета.
* **Смягченная оценка опыта**: вакансии «1-3 года» корректно классифицируются при опыте кандидата от 8 месяцев.
* **Автоматический пропуск анкет/тестов**: если отклик невозможен без заполнения анкеты (API возвращает `test_required` 403), бот отменяет отклик и показывает уведомление.
* **Кнопка `📝 Вопросы`**: выводит только новые (не показанные) вакансии с анкетами и помечает их прочитанными.
* **Защита от ловушек (Prompt Injections)**: код + системные промпты распознают требования тестовых заданий и «HR-ловушки» (например, «напишите слово банан»), такие вакансии отсекаются.
* **Валидация письма**: письмо ИИ блокируется, если содержит технические паттерны ошибок (`error`, `ошибка`, `gemini`, `api key`, `prompt` и т.п.) — защита от отправки мусора работодателю.

### Расписания
* Частота проверок мониторинга, случайный сдвиг (jitter), праймтайм и часовой пояс.
* **Сохранение расписания при перезапусках**: таймер следующего запуска атомарно сохраняется в SQLite — после рестарта контейнера бот продолжит ожидание с той же точки.

## Конфигурация (.env)

| Параметр | По умолчанию | Описание |
|---------|---------|-------------|
| TG_BOT_TOKEN | - | Токен Telegram-бота от @BotFather |
| TG_ALLOWED_USERS | - | ID пользователей Telegram через запятую |
| GEMINI_API_KEY | - | API-ключ Gemini от Google AI Studio |
| TG_PROXY_URL | - | Прокси для Telegram Bot API |
| GEMINI_PROXY_URL | - | Прокси для запросов к Gemini |
| PROXY_URL | - | Прокси для запросов к HH.ru API |
| LOG_LEVEL | INFO | Уровень логирования (DEBUG, INFO, WARNING, ERROR) |
| DATA_DIR | ./data | Каталог для SQLite-базы |

## Управление через Telegram (Reply Keyboard)
* `▶️ Запуск / ⏸ Пауза / ⏹ Стоп` — управление ручным запуском.
* `📂 Потоки` — создание и редактирование потоков: ссылка поиска, выбор резюме, лимиты (суточный / за запуск / почасовой), задержки, черный список компаний, промпты ИИ, счетчик найденных вакансий.
* `📊 Статистика` — суточная статистика успешных откликов, ошибок и пропусков.
* `📜 История` — последние обработанные вакансии с результатами.
* `📝 Вопросы` — новые вакансии, требующие ручного заполнения анкеты.
* `ℹ️ Статус и Инфо` — дашборд реального времени (активный поток, модель ИИ, состояния режимов, точка отсчета, статистика).
* `⚙️ Настройки` — выбор модели Gemini, авторизация/выход HH API, фильтр уведомлений (`🔔 Уведомления`), часовой пояс, очистка кэша, сброс лимитов.
* `🔍 Мониторинг` — настройка фонового авто-отклика (включение, интервалы, рандомизация, праймтайм).
